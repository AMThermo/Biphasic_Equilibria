# Biphasic_Equilibria
This repository contains the codes necessary to model the phase equilibria of biphasic systems measured at the Cohesion Laboratory (Concepción University) and the python codes to model such equilibria. At the time the systems included in this repository are:

*Hexane + CPME + Propanol:* Containing viscosity experimental data and its modeling with Helmholtz Scaling theory through the SAFT-VR Mie EoS.
