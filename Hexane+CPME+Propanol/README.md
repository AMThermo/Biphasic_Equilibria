# Thermophysical characterization of the synthetic oxygenate fuel mixture formed by hexane + cyclopentyl methyl ether + propan-1-ol.
This repository contains three Jupyter-Notebooks that use the sgtpy code to predict selected thermophysical properties of this ternary mixture. The notebooks also contain the experimental data measured at the Cohesion Laboratory (Universidad de Concepción). Note that you must install the sgtpy modules to use the notebooks. We refer the reader to sgtpy documentation for information on how to install it: https://github.com/gustavochm/sgtpy. 

### Documents compiled in this repository:
    - *Vapor Liquid Equilibria.ipynb*: This Jupyter-Notebook is used to carry out the VLE calculations using the ϕ−ϕ scheme and the liquid mass densities of the ternary mixture, which are based on the SAFT-VR Mie EoS
  - *Liquid viscosities - Scaling theory.ipynb*: The Jupyter-Notebook is used to fit the A-Scaling descriptive variables for each pure fluid (n-hexane, cyclopentyl methyl ether, and propan-1-ol) and their liquid viscosity as a function of temperature and the liquid viscosity for ternary mixture at 298.15 K and 101.3 kPa.
  - *Interfacial Properties.ipynb*: The Jupyter-Notebook is used to compute the surface tension for the ternary mixture at 298.15 K and 101.30 kPa as a function of the liquid mole fractions, and the interfacial profiles at given condition.
  - *experimental_data.xlsx*: This is an external Excel file which contains the experimental data.
