\f0\fs24 \cf0 # Thermophysical characterization of the synthetic oxygenate fuel mixture formed by hexane + cyclopentyl methyl ether + propan-1-ol.\
This repository contains a Jupyter-Notebook with the sgtpy code to model the viscosity each pure component, binary mixture and the ternary mixture that can be formed with Hexane, CPME and Propanol with Helmholtz Scaling theory.  The notebook also contains and plots the experimental viscosity data measured at the Cohesion Laboratory (Concepci\'f3n University). Note that you need to install the sgtpy module to use the notebook. We refer the reader to sgtpy documentation for information on how to install it: https://github.com/gustavochm/sgtpy. \
\
### Documents compiled in this repository:\
  - *Helmholtz Scaling Theory.ipynb*: The Jupyter-Notebook with the Ascaling modelling\
